# lowkey-building

Things I build while learning. Some are AI agents, some aren't. A few have detailed write-ups of what I ran into along the way, others are just the code. Not everything here is polished, and that's fine, the point is building and learning in public, not showcasing finished products.

## Projects

| Project | What it does | Status |
|---|---|---|
| [voice-note-router](./voice-note-router) | Speak a thought, it gets classified and routed to the right list (grocery/task/idea), with real voice input, not just text | Working, in daily use. Has a detailed build log |
| [game-of-life](./game-of-life) | RPG-style self-growth app — level up real-life skills (Social, Career, Health, Mind, Creativity) by completing daily quests for XP | Built, runs on Replit. Build log not yet written |

## On the write-ups

A few projects, starting with voice-note-router, have a BUILD_LOG.md alongside the README: the actual steps, decisions, and things that didn't work the first time. I write these because I learn better by documenting as I go, and figured they might be useful to anyone else learning to build with AI. Not every project will have one, and that's okay too.

## Stack

Claude (Anthropic API) for reasoning-heavy projects, Claude Code for development, Python for most of it. Each project's own README has specifics.
